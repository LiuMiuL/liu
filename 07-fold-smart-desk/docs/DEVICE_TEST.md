# DEVICE_TEST — 실기기 검수 방법

## 자동(한 번에)

Windows PC에 Android Studio(내장 JDK·SDK 포함)와 Git을 설치하고, 폰을 USB 디버깅으로 연결한 뒤:

```powershell
powershell -ExecutionPolicy Bypass -File tools\device-test.ps1
# 기본 대상 폴더: D:\Miu\Projects\폴드 스마트 대시보드 어플
# 다른 폴더: -Target "E:\work\fsd"   단위 테스트 생략: -SkipUnitTests   설치 생략: -NoInstall
```

스크립트가 하는 일
1. git·JDK·Android SDK 확인
2. 대상 폴더로 저장소 clone(이미 있으면 pull). GitHub ZIP을 풀어 넣은 폴더면 그대로 사용(Git 불필요). **그 밖에 비어 있지 않은 일반 폴더면 덮어쓰지 않고 멈춤**
3. 한글·공백 경로 문제를 피하려고 임시 드라이브(subst X: 등)로 연결해 빌드
4. PC 단위 테스트 + 디버그/릴리스 APK 빌드
5. 연결된 기기 정보 기록(모델·Android 버전·화면 크기·밀도)
6. **실기기 자동 테스트**(`connectedDeviceTestAndroidTest`) — 별도 테스트 앱 `com.miu.fold.dashboard.devtest`("FSD 테스트용")에서 실행되어 실제 앱 데이터와 분리. 끝나면 테스트 앱만 지워짐
7. 실제 앱 업데이트 설치(-r) → 실행 → 프로세스·크래시 로그 확인 → 화면 캡처
8. `docs/device-results/<시각>.md` 보고서 저장 → 이 내용을 Claude에게 붙여넣으면 이어서 수정

실기기 자동 테스트(`app/src/androidTest/.../DeviceSmokeTest.kt`): 첫 화면 카드, 빠른 메모 저장 후 화면 재생성 유지, 타이머 시작·실제 경과·일시정지·종료, 배치 편집 취소 시 배치 불변, 위험 URL 거절.
