# DEVICE_TEST — 실기기 검수

## 자동
저장소 전체가 든 폴더에서 `08-last-contact\tools\device-test.bat`(폰 USB 디버깅 연결). 별도 테스트 앱(`com.miu.lastcontact.devtest`, '연락기록 테스트용')에서 4개 자동 테스트 → 실제 앱 설치·실행·크래시 확인·캡처 → `08-last-contact\docs\device-results\시각.md`. 대상 폴더가 다르면 `-Target "폴더"`.

## 사람이 직접(체크리스트)

| # | 확인 | 기대 | 결과 |
|---|---|---|---|
| 1 | 사람 추가 → '연락처에서 이름·번호 가져오기' | 이름·번호 채워짐, 권한 요청 없음 | |
| 2 | 카톡 1:1 방 대화 내보내기 → 공유 → 연락 기록 | 확인 화면 → 저장 → 마지막 대화 날짜 일치 | |
| 3 | 카톡 단체방 내보내기 | 사람별로 그 사람이 말한 날만 | |
| 4 | 가져오기 → 알림 접근 허용(회색이면 '제한된 설정 허용') | 허용됨 표시 | |
| 5 | 카톡 메시지 받기(등록된 사람/모르는 사람) | 등록: 오늘 '카톡(알림)', 모름: 미확인 이름 | |
| 6 | 미확인 이름 → 사람에 연결 | 별칭 추가, 날짜 반영, 이후 자동 | |
| 7 | 통화·문자 권한 허용 → 지금 가져오기 | 등록 번호만 반영 | |
| 8 | 권한 모두 거절 | 안내만, 직접 기록 정상 | |
| 9 | 매일 알림 켜기(목표 넘긴 사람 있음) | 대략 그 시각 알림 1개 | |
| 10 | 백업 내보내기 → 앱 삭제·재설치 → 가져오기(전체 교체) | 사람·기록 복원 | |
| 11 | 폴드 펼치기 | 목록|상세 2패널 | |
| 12 | 글자 최대·다크 모드 | 잘림 없음 | |
