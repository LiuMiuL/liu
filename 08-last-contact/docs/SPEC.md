# 08. 연락 기록 (Last Contact) — 제작 명세

> 작성: 2026-10-30 · 대상: 본인 Android 폰(직접 설치, 스토어 배포 없음) · UI 한국어
> 패키지 `com.miu.lastcontact` · 폴더 `08-last-contact/` · 다른 앱(폴드 대시보드 등)과 독립

## 1. 목적

친구·가족과 **마지막으로 연락한 날짜**를 한눈에 보고, 오래 연락하지 않은 사람을 알려주는 앱.
기록 방법은 네 가지이며 모두 **날짜(와 시각)·경로·방향만 저장**하고 대화·문자 내용은 저장하지 않는다.

| 경로 | 동작 | 기본값 | 한계 |
|---|---|---|---|
| 직접 기록 | '오늘 연락함' 버튼, 과거 날짜 선택 | 항상 | — |
| 카톡 대화 내보내기 가져오기 | 카톡 채팅방 '대화 내보내기' 파일(.txt/.zip)을 공유·선택 → 날짜만 추출 | 항상 | 채팅방마다 직접. 파일 형식이 카톡 버전에 따라 다름 |
| 카톡 알림 자동 기록 | 알림 접근 권한으로 카톡 알림의 보낸 사람·시각 기록 | **꺼짐**(사용자가 켬) | 받은 메시지만, 알림이 꺼진 방·놓친 알림은 기록 안 됨 |
| 통화·문자 기록 | 통화 기록·문자함에서 등록한 번호와의 연락 날짜 | **꺼짐**(사용자가 켬) | 등록한 번호만, 카톡 통화는 제외 |

카카오 공식 API에는 대화 기록·마지막 대화 시각을 읽는 기능이 없으므로 쓰지 않는다.

## 2. 화면

| 화면 | 내용 |
|---|---|
| 사람 목록(홈) | 이름, 그룹, "마지막 연락 N일 전 · 날짜 · 경로", 목표 주기 대비 초과 일수. 정렬: 연락할 때 지난 순(기본)/오래된 순/이름. 그룹 필터, 검색. 행마다 '오늘 연락함' |
| 사람 상세 | 경로별 마지막 연락, 연락 기록 타임라인, 직접 기록 추가(날짜·메모), 사람 편집(이름, 카톡 이름 별칭, 전화번호, 그룹, 목표 주기, 메모), 삭제 |
| 가져오기 | 카톡 대화 내보내기 가져오기 → 미리보기(대화방 이름·기간·보낸 사람별 횟수·마지막 날짜) → 보낸 사람마다 '나 / 사람 연결 / 새 사람 / 무시' 선택 → 저장 |
| 미확인 이름 | 알림으로 들어왔지만 등록된 사람과 이름이 안 맞은 카톡 이름 목록 → 사람에 연결(별칭 추가 + 과거 기록 반영) 또는 무시 |
| 설정 | 내 카톡 이름, 카톡 알림 자동 기록(권한 안내), 통화·문자 가져오기(권한), 매일 연락 알림(시각), 백업·복원, 전체 삭제 |

폴드 펼침 등 넓은 화면(가용 600dp 이상)은 목록|상세 2패널.

## 3. 규칙

- '마지막 연락' = 모든 경로 기록 중 가장 최근 날짜. 날짜는 기기 시간대 기준 LocalDate로 저장(시각이 있으면 함께).
- 같은 사람·같은 날·같은 경로 기록은 1건으로 합친다(중복 방지 키).
- 경과 일수 = 오늘 − 마지막 연락 날짜. 목표 주기(일)가 있으면 초과 일수 = 경과 − 목표.
- 카톡 내보내기: 1:1 방(나 + 1명)은 그 방의 모든 대화 날짜를 그 사람과의 연락으로, 단체방은 그 사람이 말한 날짜만.
- 카톡 알림: 패키지 `com.kakao.talk`의 대화형 알림만. 단체방은 보낸 사람 이름으로 매칭. 메시지 본문은 읽어도 저장하지 않는다.
- 이름 매칭: 사람 이름 또는 '카톡 이름 별칭'과 공백 무시·대소문자 무시 완전 일치.
- 전화번호 매칭: 숫자만 남기고 +82/82 → 0으로 바꾼 뒤 완전 일치.
- 매일 알림: 하루 한 번(WorkManager, 시각은 지연 가능), 목표를 넘긴 사람이 있을 때만.

## 4. 보안·개인정보

- 인터넷 권한 없음. 모든 자료는 앱 내부 저장소에만. 클라우드 자동 백업 끔.
- 권한은 기능을 켤 때만 요청: 알림 접근(카톡 자동 기록), READ_CALL_LOG·READ_SMS(통화·문자), POST_NOTIFICATIONS(매일 알림). 거절해도 직접 기록·내보내기 가져오기는 동작.
- 연락처는 시스템 연락처 선택기로 사용자가 고른 한 명의 이름·번호만 가져온다(READ_CONTACTS 없음).
- 내보내기 파일은 메모리에서 날짜만 뽑고 원문을 저장하지 않는다. 크기 제한(텍스트 100MB, ZIP 안 txt만·총 해제 200MB).
- 직접 설치(파일 관리자로 APK 설치)한 앱은 Android 13+에서 알림 접근을 켜려면 앱 정보 ⋮ → '제한된 설정 허용'이 필요할 수 있다(앱 안에 안내).

## 5. 단계

| 단계 | 내용 |
|---|---|
| 1 | 사람·직접 기록·목록·상세·재시작 보존 |
| 2 | 카톡 내보내기 가져오기(형식 4종), 미확인 이름 연결 |
| 3 | 카톡 알림 자동 기록, 통화·문자 가져오기 |
| 4 | 매일 알림, 백업·복원, 2패널, 실기기 검수 |

## 6. 검수 시나리오

| ID | 행동 | 기대 |
|---|---|---|
| LC-T01 | 사람 추가 → 오늘 연락함 → 앱 재시작 | 0일 전 유지 |
| LC-T02 | 과거 날짜 직접 기록 | 경과 일수 정확, 미래 날짜 거절 |
| LC-T03 | 같은 날 같은 경로 여러 번 | 1건 |
| LC-T04 | 카톡 1:1 내보내기(안드로이드/PC/iOS 형식) | 마지막 대화 날짜 = 파일 마지막 날짜 |
| LC-T05 | 카톡 단체방 내보내기 | 그 사람이 말한 날짜만 |
| LC-T06 | 형식이 아닌 파일·거대 파일·ZIP 폭탄 | 거절, 앱 정상 |
| LC-T07 | 카톡 알림(1:1, 단체, 광고·시스템) | 대화만 기록, 미등록 이름은 미확인 목록 |
| LC-T08 | 미확인 이름을 사람에 연결 | 별칭 추가, 과거 날짜 반영 |
| LC-T09 | 통화·문자(+82 번호 포함) | 등록 번호만 매칭 |
| LC-T10 | 권한 거절 | 해당 기능 안내, 나머지 정상 |
| LC-T11 | 자정·시간대 변경 | 경과 일수 재계산 |
| LC-T12 | 백업 → 복원(새로 추가/교체) | 사람·기록 보존, 중복 없음 |
