# 참고 저장소 분석 — alexch33/super-video-downloader

- 확인: 2026-10-30, 커밋 `a5eb7c8` (2026-10-27)
- 라이선스: **GPL-3.0**. 코드를 복사하면 이 앱 전체가 GPL-3.0 의무를 지게 되므로 **코드는 한 줄도 복사하지 않았고**, 동작 방식만 참고해 직접 구현했다.
- 저장소는 빌드하거나 실행하지 않았다(읽기만).

## 그 앱의 구성

Android View + DataBinding, Dagger 2, RxJava, Room. 내장 브라우저(웹 페이지의 m3u8/mpd 요청 가로채기),
Rust 광고 차단, v2ray(Go) 프록시·DoH, 내장 플레이어, 다운로더 여러 종(yt-dlp, 자체 HLS/DASH 조각 다운로더, 일반 HTTP).

## 반영한 것

| 참고한 점 | 이 앱에서 |
|---|---|
| yt-dlp에 `--newline`, `--progress` 사용 | `--newline` 채택 — 진행률·제목 해석을 줄 단위로 안정화 |
| `-N <스레드>`로 조각 동시 다운로드 | `-N 4` 채택(HLS/DASH 속도) |
| 앱 시작마다 yt-dlp 자동 업데이트(개발판 master 채널) | **안정판(stable)** 으로, **하루 1회**, 설정에서 끌 수 있게 바꿔 채택 |
| 취소와 실패를 구분하는 오류 처리 | 사용자 취소/시스템 중단/실패를 구분(QueueProcessor) |
| 저장 위치 Downloads | 채택 안 함 — 갤러리에 보이도록 Movies/Music |

추가로 직접 설계: 사이트 변경 오류(추출 실패·봇 차단) 시 엔진 업데이트 후 **그 링크만 1회 자동 재시도**.

## 반영하지 않은 것과 이유

| 기능 | 이유 |
|---|---|
| 내장 브라우저·스트림 가로채기 | "공유 한 번에 저장" 범위를 크게 넘음. 후속 후보(TASKS VG-X1) |
| 브라우저 로그인 쿠키를 yt-dlp에 전달 | 계정 쿠키 취급·이용약관 위험. 사용자 확인 전 보류 |
| v2ray 프록시·DNS 우회 | 우회 기능이며 이 앱 목적과 무관 |
| 광고 차단(Rust) | 브라우저가 없으므로 불필요 |
| 고아 python/ffmpeg 프로세스 정리 | 이 앱은 WorkManager 한 작업에서만 실행하고 종료 시 `destroyProcessById`로 정리. 실기기에서 문제가 보이면 검토 |
