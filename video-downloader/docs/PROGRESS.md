## 진행 중 발견·수정
1. 실제 yt-dlp 출력에서 조각 파일 형식 ID가 문자 포함(`.faud-Korean.mp4`) → 숫자만 보던 판별식 수정.
2. 사이트에 따라 영상 ID가 한글(`[단일 영상]`) → 제목에서 `[ID]` 제거식 수정.
3. 봇 확인 오류 문구에 `--cookies`가 들어 있어 "로그인 필요"로 잘못 분류 → 순서 수정. 지역 제한 문구 보강.
4. `...watch?v=AAA/`가 중복으로 안 잡힘 → 정규화에서 끝 '/' 제거.
5. 테스트 환경 로캘 때문에 한글 파일명이 깨져 테스트가 틀린 결과 → 테스트 JVM UTF-8.
6. 참고 저장소(super-video-downloader, GPL-3.0) 분석 → `--newline`, `-N 4`, 엔진 자동 업데이트(안정판·하루 1회로 변경) 반영, 코드 복사 없음.
