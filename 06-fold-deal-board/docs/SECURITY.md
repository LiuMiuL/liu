# SECURITY — Fold Deal Board

## 권한

- 앱이 선언한 권한: **없음**. 인터넷 권한도 없다(외부 통신 기능이 없음). 병합된 APK에는 AndroidX core가 자동 추가하는 앱 내부 전용 `com.miu.fold.deals.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`만 있다(`aapt2 dump permissions`로 확인).
- 위치·연락처·SMS·저장소 전체 접근·카메라·접근성 서비스 요구하지 않음.
- 알림 권한은 MKT-09 구현 시 필요한 시점에만 요청할 예정.

## 저장 범위

- 앱 전용 내부 저장소의 Room DB(`fold_deal_board.db`)만 사용. 다른 앱 DB를 읽지 않는다.
- 앱 수준 암호화는 하지 않는다(Android 기본 앱 샌드박스·기기 암호화에 의존). 둘은 다른 보호 수준이다.
- OS 클라우드 백업·기기 이전 대상에서 제외(`allowBackup=false`, `data_extraction_rules.xml`).
- 앱 삭제 시 데이터도 삭제된다.

## 외부 데이터 처리

- 다른 앱에서 공유받은 텍스트는 **데이터로만** 저장한다(링크·제목·설명 추출). 명령으로 실행하지 않는다. 최대 20,000자.
- 공유 Intent는 액티비티 재생성 시 다시 처리하지 않는다.
- 원본 링크는 http/https만 저장·열기 허용(`javascript:`, `intent:` 등 거절). 열 때 `CATEGORY_BROWSABLE`로 브라우저 앱에 넘기며 열 앱이 없으면 아무 것도 하지 않는다.
- 웹페이지를 읽거나 자동 수집하지 않는다. 판매자에게 메시지·결제·구매를 자동으로 하지 않는다.
- 판매자 연락처·계좌는 기본 수집하지 않으며 입력 화면에 안내 문구를 둔다.

## 비밀정보

- API 키·토큰·서명키 없음. 디버그 서명만 사용. `local.properties`는 Git 제외.

## 남은 위험·후속

- 내보내기(MKT-11): CSV 수식 주입(`= + - @` 시작) 방지 필요.
- 백업 파일(MKT-12): 평문 JSON이면 메모에 개인정보가 포함될 수 있음을 표시해야 함.
- 첨부(MKT-02b): 시스템 선택기 사용, 앱 내부 복사, 전체 저장소 권한 미사용.
